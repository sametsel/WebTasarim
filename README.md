# Web Tasarım Çalışmaları

Web tasarım dersi kapsamında hazırlanmış HTML, CSS, Bootstrap, JavaScript ve TypeScript örnekleri.

## İçerik

| Klasör | Konu |
|--------|------|
| `HTML/` | Temel HTML sayfaları |
| `CSS/` | Stil ve düzen örnekleri |
| `Bootstrap/` | Bootstrap ile responsive arayüzler |
| `JavaScript/` | DOM ve etkileşim örnekleri |
| `TypeScript/` | TypeScript alıştırmaları |
| `jquery/` | jQuery örnekleri |
| `Car_Project/`, `proje1/`, `proje2/` | Küçük proje çalışmaları |

## Nasıl bakılır?

Her klasördeki `.html` dosyalarını tarayıcıda açabilirsiniz. Ayrı bir build adımı yoktur.

```bash
git clone https://github.com/sametsel/WebTasarim.git
cd WebTasarim
# Örnek: bir HTML dosyasını tarayıcıda açın
```

## Amaç

Frontend temellerini pekiştirmek: semantik HTML, CSS düzeni, Bootstrap grid ve temel JS/TS.
